# N-Queens Simulated Annealing

Interactive browser-based visualization of the N-Queens problem using Simulated Annealing.

## Run locally
Open `index.html` in a browser.

## Deploy to Vercel
1. Push these files to a GitHub repository.
2. In Vercel, choose **Add New → Project** and import the repository.
3. Leave Framework Preset as **Other**.
4. Leave Build Command and Output Directory empty (or use `.` as the output directory if prompted).
5. Click **Deploy**.

No Matplotlib, Python packages, or build step required.
